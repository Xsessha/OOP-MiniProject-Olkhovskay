# User Guide

## Призначення

Car Rent System допомагає вести простий автопарк: дивитися автомобілі, орендувати їх, повертати та перевіряти базову аналітику.

## Запуск

```bash
dotnet run --project src/CarRentSystemstem.Console/CarRentSystem.Console.csproj
```

Після запуску з'явиться меню:

```text
1. Rent car
2. Return car
3. Show cars
4. Analytics
0. Exit
```

## Перегляд автомобілів

Оберіть `3. Show cars`. Таблиця показує:

- `ID` - ідентифікатор, який потрібен для оренди або повернення;
- `MODEL` - модель автомобіля;
- `PRICE` - ціна за день;
- `STATUS` - `Available` або `Rented`.

## Оренда автомобіля

1. Оберіть `1. Rent car`.
2. Скопіюйте `ID` доступного автомобіля з таблиці.
3. Введіть ім'я клієнта.
4. Введіть тип клієнта: `economy` або `premium`.
5. Введіть `Car ID`.
6. Введіть кількість днів.

Правила:

- `economy` має 5% знижки і може орендувати максимум на 10 днів;
- `premium` має 20% знижки;
- кількість днів має бути від 1 до 365;
- повторно орендувати вже зайнятий автомобіль не можна.

## Повернення автомобіля

1. Оберіть `2. Return car`.
2. Введіть `Car ID` орендованого автомобіля.
3. Система змінить статус на `Available` і покаже підсумкову вартість.

Якщо дата повернення пізніша за очікувану, додається штраф: `ціна за день * кількість днів прострочення * 1.5`.

## Аналітика

Оберіть `4. Analytics`, щоб побачити:

- загальний дохід з усіх зафіксованих оренд;
- топ-5 моделей за кількістю оренд.

## Збереження та відновлення

Стан автомобілів зберігається у файлі `cars.json` після оренди або повернення. Після повторного запуску застосунок читає цей файл і відновлює статуси авто.

Якщо `cars.json` відсутній, застосунок стартує зі стандартним автопарком. Якщо JSON пошкоджений, користувач бачить warning, а застосунок переходить до стандартного списку.

## Типові помилки

- Невідомий тип клієнта: введіть тільки `economy` або `premium`.
- Некоректний `Car ID`: введіть GUID з таблиці автомобілів.
- Автомобіль уже орендовано: виберіть інший `Available` автомобіль.
- Немає активної оренди для повернення: перевірте, чи цей автомобіль справді має статус `Rented`.
